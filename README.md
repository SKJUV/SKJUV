### 👨‍💻 À Propos de Moi

Ingénieur logiciel et concepteur de solutions passionné par l'**architecture de systèmes distribués**, le **développement bas niveau haute performance** et l'**intégration d'agents IA autonomes**.

- 🔭 **Actuellement focalisé sur** : La conception d'agents locaux via le protocole **MCP (Model Context Protocol)** et les moteurs de scoring transactionnel FinTech.
- ⚡ **Maîtrise technique** : De la programmation système en **Rust** aux architectures cloud **Docker / Azure / AWS**, en passant par les applications web réactives (**Next.js, Django, TypeScript**).
- 🌍 **Impact concret** : Conception de solutions adaptées aux réalités économiques et industrielles africaines (Mobile Money MTN/Orange, dimensionnement photovoltaïque, ERP SIRH B2B).
- 💬 **Parlons de** : Systèmes distribués, intégration LLMs, WebSockets, concurrence, et conception SaaS de 0 à la production.
