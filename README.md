### 👨‍💻 À Propos de Moi

Ingénieur logiciel et concepteur de solutions techniques passionné par l'**architecture de systèmes distribués**, la **performance bas niveau** et l'**intégration d'agents IA autonomes**.

- 🔭 **Focus Actuel** : Conception d'agents locaux autonomes via le protocole standard **MCP (Model Context Protocol)** et algorithmes de scoring financier pour l'Afrique.
- ⚡ **Maîtrise Technique** : De la programmation système en **Rust** aux architectures cloud **Docker / Azure / AWS**, en passant par les applications réactives **Next.js, React Native, Django et TypeScript**.
- 🌍 **Impact Industriel** : Développement de plateformes adaptées aux défis réels (Mobile Money MTN/Orange, dimensionnement solaire photovoltaïque, ERP SIRH B2B CEMAC).
- 💬 **Échangeons sur** : Architectures microservices, WebSockets, concurrence mémoire, intégration de LLMs et conception logicielle résiliente.
